# Dreams Calendar — frequently asked questions

## What should I check when using entries?

These are self-reported observations; missing entries are not equivalent to a normal or symptom-free day.

## What should I check when using review?

A chart association does not establish cause, diagnosis or treatment effect.

## What should I check when using storage?

Do not assume export or cross-device recovery. The site explicitly says it is not for users needing sync/export.

## Where should I start?

Use the quick-start guide with a small example, verify the saved result, then choose a practical workflow. Avoid beginning with irreplaceable data or an entire production project.

## How do I report a documentation or app problem?

Use the official product support channel for account or purchase issues. A public GitHub issue is suitable for documentation corrections and sanitized reproduction steps. Include the app version, device/OS, expected outcome and actual result; do not attach private data.
