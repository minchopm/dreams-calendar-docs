# Dreams Calendar — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Record an uncertain memory without inventing data

### Before you begin

Choose the correct entry type and date.

### Steps

1. Write the remembered fragments first.

2. Add emotions that actually fit the memory.

3. Enter sleep estimates only when you can reasonably recall them.

4. Skip uncertain fields rather than filling them with normal-looking values.

5. Save and check the calendar date.

### Expected result

The entry distinguishes remembered observations from missing information.

### If the result differs

The charts reflect self-reporting; a missing day is not a symptom-free day.

## Procedure 2: Read a monthly pattern carefully

### Before you begin

Use a date range with enough recorded entries to inspect.

### Steps

1. Select the intended month or range.

2. Check how many entries contribute to the pattern.

3. Look for missing days or changes in your logging routine.

4. Compare relevant observations without assuming causation.

5. Use the result as a reflection prompt.

### Expected result

You understand the data behind the visible pattern.

### If the result differs

The app is not a diagnostic tool. Its site does not promise sync/export; do not assume recovery after uninstalling or changing devices.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
