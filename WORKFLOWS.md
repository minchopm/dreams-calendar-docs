# Dreams Calendar — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## A five-minute morning record

Capture a few anchor details first: place, person or feeling. Add the sleep window and quality if known. Use the same rough routine each morning so the log reflects comparable observations rather than a changing definition of quality.

## An evening reflection

Describe what happened and how you felt without trying to force a positive score. Distinguish a day reflection from a night-dream entry. A short honest record is more useful than a long reconstructed narrative written much later.

## Read a monthly chart

Check the date filter and how many entries contribute. Missing days can change the apparent pattern. Use the view as a prompt for reflection, not as evidence that a particular dream or habit caused a health outcome.
